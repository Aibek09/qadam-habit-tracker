# Changelog

All notable changes to QADAM are documented here.

## [Unreleased]

### Added

- Focus timer for tasks measured in minutes.
- Start, stop, continue, and finish workflow.
- Automatic conversion of elapsed seconds into task progress.
- Automatic addition of a finished session to the selected day’s existing progress.
- Local recovery of an active or paused timer after a page refresh.
- Responsive timer controls for desktop and iPhone layouts.
- Russian and English timer interface text.

### Changed

- Progress and report values are normalized to one decimal place for clean time totals.
